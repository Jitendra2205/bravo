I replaced $100+ a month of AI agents with a private one that runs on my laptop for $0.

The problem

Always-on agents like ChatGPT dots and Grok Bot cost $100+ a month and live in someone else's cloud. Good dictation is another subscription. I wanted the same habits — talk, delegate, get a morning brief — without the bill or the data leaving my machine.

What I chose, and why

OptionDecision
Paid cloud agentsStrongest, but $100+/month and cloud-only
Build an agent from scratchMonths of work open source already did
Five existing one-click installersA sixth adds nothing; none hardened by default
Hermes Agent + Ollama + WhisperChosen. My work went into security, custom skills and evaluation

Architecture

You (voice / hotkey / keyboard)
 ├─ Handy ─ local Whisper ─ types into any app
 └─ Hermes Agent (WSL2) ─ Whisper in / NeuTTS out
      ├─ Ollama, localhost only ─ gemma4:e4b
      └─ Docker sandbox ─ sees one folder
Optional, off by default: Telegram, Claude/Gemini API
